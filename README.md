# 🎨 AI 브랜드 아이덴티티 생성기

> 브랜드 브리프(JSON) 하나로 **네이밍 · 슬로건 · 브랜드 스토리 · 컬러 팔레트 · 로고 시안**을 자동 생성하는 Python CLI 프로그램

LLM API로 텍스트 브랜드 요소를 만들고, 이미지 생성 API로 로고 시안을 만든 뒤, 모든 결과물을 지정한 폴더에 저장합니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목표 | 브랜드 브리프 입력 → AI로 브랜드 요소 자동 생성 → 파일로 저장 |
| 언어 | Python 3.10 이상 |
| 텍스트 생성 | Google Gemini (무료) / Anthropic Claude / OpenAI 중 가지고 있는 키로 자동 선택 |
| 이미지 생성 | Pollinations.ai (무료, 키 불필요) 또는 OpenAI DALL-E |
| 시각화 | matplotlib |
| 외부 패키지 | `requests`, `matplotlib` |

브랜드 디자인 외주는 네이밍, 슬로건, 컬러, 로고가 각각 전문 작업이라 비용과 시간이 많이 듭니다. 이 프로그램은 그 초안 작업을 브리프 하나로 자동화합니다.

## 2. 주요 기능

| 단계 | 생성 내용 | 저장 |
|---|---|---|
| [1/5] 브랜드 네이밍 | 후보 3~5개 + 의미/유래, **한글·영문 동시 생성** | `brand_result.json` |
| [2/5] 슬로건 | 톤앤매너를 반영한 슬로건/태그라인 3개 | `brand_result.json` |
| [3/5] 브랜드 스토리 | 탄생 배경·철학·비전을 담은 300자 내외 스토리 | `brand_result.json` |
| [4/5] 컬러 팔레트 | 메인 1개 + 서브 2~3개 (HEX) | `brand_result.json`, `color_palette.png` |
| [5/5] 로고 시안 | 이미지 생성 API로 로고 2개 | `logo_01.png`, `logo_02.png` |
| [보너스] 경쟁사 분석 | 경쟁사별 포지셔닝·강점·약점 + 차별화 포인트 | `brand_result.json` |

## 4. 설치 및 실행

### 4-1. 패키지 설치

```powershell
python -m pip install --user -r requirements.txt
```

> `pip.exe`가 보안 정책으로 차단된 PC에서도 `python -m pip`로 설치할 수 있습니다.

### 4-2. API 키 설정

API 키는 **코드에 직접 쓰지 않고** 환경 변수 또는 `.env` 파일에서 읽습니다. 아래 키 중 **하나만** 있으면 됩니다.

| 키 | 비용 | 발급 |
|---|---|---|
| `GEMINI_API_KEY` | 무료 (구글 계정만 필요) | https://aistudio.google.com/apikey |
| `ANTHROPIC_API_KEY` | 유료 크레딧 (Claude Pro 구독과 별도) | https://platform.claude.com |
| `OPENAI_API_KEY` | 유료 크레딧 (ChatGPT Plus 구독과 별도) | https://platform.openai.com/api-keys |

프로그램 폴더에 `.env` 파일을 만들어 한 줄로 저장합니다.

```powershell
Set-Content -Path .env -Value 'GEMINI_API_KEY=AIza발급받은키' -Encoding UTF8
```

또는 실행할 때마다 환경 변수로 설정할 수 있습니다.

```powershell
$env:GEMINI_API_KEY="AIza발급받은키"      # Windows PowerShell
export GEMINI_API_KEY=AIza발급받은키      # macOS / Linux
```

### 4-3. 브리프 작성 (`brief.json`)

```json
{
  "industry": "친환경 화장품",
  "target": "20-30대 여성",
  "keywords": ["자연", "순수", "건강"],
  "tone": "따뜻하고 신뢰감 있는",
  "competitors": ["이니스프리", "아로마티카"],
  "notes": "비건 인증과 재활용 패키지를 강조하고 싶음"
}
```

- 필수: `industry`(업종), `target`(타겟), `keywords`(키워드)
- 선택: `tone`(톤앤매너), `competitors`(경쟁사), `notes`(추가 요청사항)

## 5. 동작 파이프라인

```
┌──────────────┐
│ brief.json   │  필수 필드 검증 (industry, target, keywords)
└──────┬───────┘
       ▼
[1/5] 네이밍 ──────► 첫 번째 후보를 "대표 브랜드명"으로 선정
       ▼
[2/5] 슬로건 ─┐
[3/5] 스토리 ─┼────► 대표 브랜드명 + 브리프를 프롬프트에 넣어 일관성 유지
[4/5] 컬러 ───┘ ───► HEX 검증 → matplotlib → color_palette.png
       ▼
[5/5] 로고 ────────► 브랜드명 + 키워드 + 톤 + 컬러 팔레트로 이미지 프롬프트 작성
       ▼                → 이미지 API → PNG 변환 → logo_01.png, logo_02.png
[보너스] 경쟁사 분석
       ▼
brand_result.json 저장 (모든 텍스트 결과 + 실패 단계 기록)
```

**설계 포인트**
- **단계 연결:** 네이밍 결과를 이후 모든 단계에 넘겨서, 슬로건·스토리·컬러·로고가 하나의 브랜드로 이어지게 했습니다.
- **JSON 응답 강제:** LLM에 JSON 형식을 지정해 받고(Gemini `responseMimeType`, OpenAI `response_format`), 코드블록으로 감싸 오는 응답도 파싱합니다.
- **결과 검증:** 네이밍 개수(3~5), 슬로건 개수(3), 스토리 길이(250~350자), HEX 형식, 서브 컬러 개수(2~3)를 코드로 다시 확인합니다. 스토리 길이가 벗어나면 한 번 다시 생성합니다.
- **PNG 보장:** 이미지 API가 JPEG 등 다른 형식으로 보내도 Pillow로 PNG로 변환해 저장합니다.
- **한글 폰트:** Windows(맑은 고딕), macOS(AppleGothic), Linux(Noto Sans CJK)를 자동으로 찾아 팔레트 이미지에 한글이 깨지지 않게 했습니다.

## 7. API 오류 처리

| 상황 | 프로그램 동작 |
|---|---|
| API 키 없음 | 키 종류별 발급 주소와 설정 방법을 안내하고 종료 |
| 키 형식 오류 (예: Gemini 자리에 OpenAI 키) | 형식이 틀렸다고 알려 주고 종료 |
| 키 거부 (401, Gemini `API key not valid`) | 안내 출력 → 같은 API를 쓰는 남은 단계는 건너뜀. 키가 필요 없는 로고 생성은 계속 진행 |
| 요청 한도 초과 (429), 서버 오류 (5xx) | 잠시 기다린 뒤 최대 3회 시도. Gemini가 알려 주는 대기 시간(`retry in Ns`)을 따름 |
| 모델 없음 (404), 무료 티어 미지원 (`limit: 0`) | 다음 후보 모델로 자동 전환 |
| 크레딧 부족, 하루 무료 사용량 소진 | 재시도 없이 원인을 안내하고 다음 단계 진행 |
| 네트워크 끊김, 타임아웃 | 재시도 후 실패하면 다음 단계 진행 |
| 응답이 JSON이 아님, HEX 오류, 개수 부족 | 해당 단계 실패 처리 후 다음 단계 진행 |
| 네이밍 실패 | 업종명을 임시 브랜드명으로 써서 이후 단계 계속 |

모든 실패는 `brand_result.json`의 `errors`에 단계 이름과 함께 기록됩니다.

## 8. 개발 과정과 문제 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| `pip.exe` 실행 차단 | PC의 애플리케이션 제어 정책이 `pip.exe` 파일을 막음 | `python -m pip install --user`로 설치 |
| `export` 명령 인식 안 됨 | `export`는 macOS/Linux 명령이라 PowerShell에 없음 | PowerShell은 `$env:이름="값"` 사용, 안내 문구도 수정 |
| API 키를 못 찾음 | 환경 변수가 창을 새로 열면 사라짐 | 프로그램 폴더의 `.env`도 찾도록 수정, 메모장 BOM 처리 |
| OpenAI 401 오류 | API는 ChatGPT 구독과 별개로 크레딧 충전이 필요 | 무료 Gemini API 지원 추가 |
| 무료 이미지 생성 | Gemini 무료 티어는 이미지 생성 모델 할당량이 없음 | 키 없이 쓰는 Pollinations.ai로 로고 생성 |
| Claude Pro로 API 사용 | Pro 구독에는 API 사용이 포함되지 않음 | Console 크레딧으로 쓸 수 있도록 Claude API도 지원 |
| 실행 예시와 다른 출력 | 경쟁사가 있으면 단계 수가 `[1/6]`으로 바뀜 | `[1/5]`~`[5/5]` 고정, 경쟁사 분석은 `[보너스]`로 분리 |

## 9. 테스트

```bash
python test_mock.py
```

API 키나 인터넷 없이, HTTP 응답만 가짜 서버로 바꾸고 나머지 코드는 실제로 실행해 검증합니다.

| 시나리오 | 확인 내용 |
|---|---|
| A. 정상 흐름 | 5단계 + 보너스 결과, PNG 3개(JPEG 응답도 PNG로 저장), 잘못된 경로 재입력, 기본 출력 폴더 |
| B. 부분 실패 | 모델 404 → 다음 모델 시도, 서버 오류 재시도 후 실패 → 다음 단계 계속 진행 |
| C. 잘못된 키 | 텍스트 단계는 건너뛰고 로고는 생성, 키 거부 후 불필요한 재호출 없음 |
| D. Claude 키 | Claude 자동 선택, 코드블록 JSON 응답 파싱 |
| E. 입력 오류 | 키 없음, 키 형식 오류, 브리프 필수 필드 누락 |

## 마무리

이 프로젝트를 통해 다음 내용을 직접 구현하고 정리했습니다.

- **AI 브랜드 생성 파이프라인:** 브리프 → 네이밍 → 슬로건·스토리·컬러 → 로고로 이어지며, 앞 단계 결과를 다음 단계 프롬프트에 넘겨 하나의 브랜드로 완성하는 구조
- **LLM + 이미지 API 조합:** 텍스트는 JSON으로 받아 검증하고, 그 결과(브랜드명·키워드·컬러)로 이미지 프롬프트를 만들어 로고를 생성하는 방법
- **컬러 팔레트 시각화:** HEX 코드를 matplotlib 사각형으로 그리고, 배경 밝기에 따라 글자색을 바꿔 PNG로 저장하는 방법
- **API 오류 대응:** 키 오류·요청 한도·서버 오류·모델 없음·응답 형식 오류를 구분하고, 재시도·대체 모델·단계 건너뛰기로 프로그램이 끝까지 결과를 저장하게 하는 방법
